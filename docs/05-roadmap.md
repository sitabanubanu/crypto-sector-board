## 第二程：交易增强（阶段 7-10）

### 阶段 7 — 多时间维度对比 ✅
**目标**：不只是看"现在谁涨"，还能看"谁在持续走强/走弱"。

- [x] 7-A PostgreSQL 日级历史与批量 `/api/v1/history`
- [x] 7-B `components/TrendBarChart.tsx`：板块 × 四周期柱状对比
- [x] 7-C 支持 24h / 3d / 7d / 30d
- [x] 7-D 缺失数据保持 `N/A`，颜色使用红涨绿跌

**验收**：能看到"DeFi 连续 3 天走强，Memecoin 连续 2 天走弱"这样的信息。

**交易价值**：轮动交易的核心依据——跟着连续走强的板块做多，回避连续走弱的板块。

---

### 阶段 8 — 板块轮动 + 异动检测 ✅（P5.1）
**目标**：系统自动帮你发现值得关注的信号，不用人盯着看。

- [x] 8-A `lib/signals.ts`：`market-pulse-v1` 可解释信号引擎
  - 轮动：当前排名相对上一完整 UTC 日变化至少 3 位
  - 异动：至少 20 个历史样本且 `|z| >= 2`
  - 数据过期、覆盖不足或样本不足时不触发
- [x] 8-B `components/MarketPulseBar.tsx`：市场广度、排名、贡献者、信号原因与质量
- [x] 8-C 首页资产/板块搜索联动高亮 Treemap 和柱状图

**验收**：如果某个板块突然暴涨，页面顶部自动出现一条红色信号条。

**交易价值**：从"被动看图"变成"主动被提醒"，盘中不需要一直刷新。

---

### 阶段 9 — 成交活跃度与量价分化
**目标**：比较成交活跃度和价格变化，不把成交量误写成真实资金流入。

- [ ] 9-A `lib/metrics.ts` 新增 `weightedVolumeReturn`：用 24h 成交量作为权重计算板块涨跌
- [ ] 9-B 对比“市值加权涨跌”和“成交量加权涨跌”，只描述量价分化
- [ ] 9-C `components/FlowIndicator.tsx`：显示成交活跃度及其数据来源

**验收**：BTC 市值加权涨 1% 但成交量加权涨 5% 时，只提示“成交量权重下表现更强”，不推断大资金流入。

**观察价值**：帮助识别量价是否分化；该指标不能证明吸筹、出货或净流入。

---

### 阶段 10 — 移动端适配
**目标**：手机打开不再看缩小的 Treemap，而是专用列表视图。

- [ ] 10-A `components/MobileListView.tsx`：按板块分组、按涨跌排序的列表
- [ ] 10-B `app/page.tsx` 根据屏幕宽度自动切换 Treemap / 列表
- [ ] 10-C 列表每行显示：板块名、加权涨跌、市值、成交量热度

**验收**：手机浏览器打开自动显示列表，字体大小可读，不需要缩放。

## 第三程：个人化（阶段 11-13）

### 阶段 11 — 关注资产与真实持仓拆分
**目标**：先提供不误导的关注标记；真实持仓必须有用户录入的数量和成本。

- [x] 11-A `data/sectors.json` 使用 `focusAssets` 规范资产 ID 数组
- [x] 11-B Treemap 中关注资产加金色星标，并明确“非真实持仓”
- [ ] 11-C 真实持仓模型：资产、数量、成本、计价币、录入/更新时间
- [ ] 11-D 基于用户仓位计算总市值和今日盈亏；不得使用全网市值代替

**验收**：关注资产与真实持仓在数据结构和文案上完全分离。

---

### 阶段 12 — 板块相关性矩阵 ✅（P5.0）
**目标**：知道哪些板块是同涨同跌的，避免押注在同一方向。

- [x] 12-A `lib/correlation.ts`：UTC 日收益按日期 inner join，至少 30 个共同样本
- [x] 12-B `components/CorrelationHeatmap.tsx`：相关性热力图；无效结果显示 `N/A`
- [x] 12-C 单元格保留共同样本数，并提示相关不代表因果

**验收**：能看到“AI 与 Memecoin 相关系数 0.85、共同样本 n=30”，数据不足时显示 `N/A`。

**观察价值**：帮助识别样本期内共同波动较高的板块；它不证明因果，也不能单独替代仓位和风险判断。

---

### 阶段 13 — Telegram 推送
**目标**：不用打开网页也能收到每小时摘要和异动提醒。

- [ ] 13-A GitHub Actions 中抓完后调用 Telegram Bot API
- [ ] 13-B 推送内容：板块涨跌排名 Top 5 + Bottom 3 + 异动信号（如有）
- [ ] 13-C 用户提供自己的 Telegram Chat ID 配置到 GitHub Secrets

**验收**：手机 Telegram 每小时收到一条板块摘要消息。
